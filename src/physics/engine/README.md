## References & Bibliography

* **Catto, E.** (2005–2024). *Iterative Dynamics with Temporal Coherence*. Game Developers Conference (GDC) / Box2D Documentation.
  *(Foundational reference for the Sequential Impulse solver, warm starting, and Baumgarte positional stabilization).*

* **Catto, E.** (2006). *Box2D Lite: A Fast and Simple 2D Physics Engine*. open-source C++ codebase.
  *(Reference architecture for type-dispatch narrow phase, shape-pair routing, and contact manifold generation).*

* **Eberly, D. H.** (2010). *3D Game Engine Design: A Practical Approach to Real-Time Computer Graphics* (2nd ed.). Morgan Kaufmann.
  *(Mathematical formulations for the Separating Axis Theorem (SAT), convex polygon projections, and supporting geometric query routines).*

* **Sutherland, I. E., & Hodgman, G. W.** (1974). *Reentrant Polygon Clipping*. Communications of the ACM, 17(1), 32–42.
  *(The algorithmic basis for clipping incident polygon faces against reference planes to extract multi-point contact manifolds).*

* **Baraff, D.** (2001). *An Introduction to Rigid Body Simulation*. Robotics and Automation Course Notes, Carnegie Mellon University / Pixar Animation Studios.
  *(Core principles of rigid body kinematics, impulse-momentum transformations, and moment of inertia tensor formulations).*
